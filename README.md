# Aulora

**Organização inteligente para quem ensina.**

Plataforma de gerenciamento escolar com o assistente **Plusck** (Gemini).

## Como usar

Abra `index.html` no navegador ou:

```bash
cd aulora   # ou professor-hub
python3 -m http.server 3000
```

## Conta

- Cadastro: nome, e-mail, senha (+ dica de recuperação)
- Login: e-mail + senha
- Dados só neste navegador/PC

## Plusck

Cada turma guarda o próprio histórico de conversas.
Modelo padrão: Gemini 3.5 Flash (com fallback automático).

## Funcionalidades

Turmas, alunos, mapa de sala, presença, notas, atividades, planejamento, comunicados, relatórios.
